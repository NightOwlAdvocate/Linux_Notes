# Documentation

This directory adds navigation and learning material without moving the original Ubuntu notes.

- [`case-studies/`](case-studies/README.md) — verified incidents, outcomes and evidence limits.
- [`learning/`](learning/kubernetes-two-day-plan.ru.md) — bounded learning plans with practical exercises.
- [`roadmap/`](roadmap/canonical-portfolio.md) — honest separation between completed work and future portfolio goals.

New incident write-ups should follow this sequence:

1. context and exact environment;
2. symptoms and captured evidence;
3. hypotheses and tests;
4. safe changes made;
5. verification and remaining uncertainty;
6. rollback or recovery procedure;
7. lessons learned.
